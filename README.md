# سيرة محمد العمراني

صفحة سيرة ذاتية عربية (RTL) بثلاثة ملفات فقط، بدون مكتبات. افتح `index.html` في المتصفح، أو اضغط «طباعة السيرة» ثم «حفظ بصيغة PDF».

**الرابط المباشر:** https://mohammedorax.github.io/mohammed-cv/

## الملفات

| الملف | ماذا يفعل |
| --- | --- |
| `index.html` | يكتب المحتوى: الاسم والتخصص وبيانات التواصل والأقسام. |
| `style.css` | يعطي الشكل: الألوان والخطوط والمسافات والتخطيط. |
| `script.js` | يضيف التفاعل: تبديل الوضع الليلي وفتح نافذة الطباعة. |

## أفكار HTML الأساسية

- `dir="rtl"` يجعل اتجاه الصفحة من اليمين إلى اليسار.
- `header` و`main` و`aside` و`section` عناصر دلالية توضح وظيفة كل جزء.
- `mailto:` يفتح البريد، و`tel:` يتصل من الهاتف.
- `defer` يؤجل تشغيل السكربت حتى تجهز الصفحة.

## أفكار CSS الأساسية

- المتغيّرات (`--brand` وغيرها) تجمع الألوان في مكان واحد.
- `[data-theme="dark"]` يعيد تعريف نفس المتغيّرات للوضع الليلي.
- `display: grid` مع `1.7fr 1fr` يصنع عمودين، ويتحول لعمود واحد في الجوال.
- `@keyframes rise` حركة ظهور بسيطة، و`prefers-reduced-motion` يوقفها لمن يريد.
- `@media print` يخفي الأزرار ويحوّل الصفحة لورقة A4 نظيفة.

## أفكار JavaScript الأساسية

- `querySelector` يبحث عن عنصر بالمعرّف `id`.
- `addEventListener("click", ...)` ينفّذ دالة عند الضغط.
- `localStorage` يحفظ الوضع المختار بعد إغلاق الصفحة.
- `window.print()` يفتح نافذة الطباعة.

## التخصيص

1. استبدل الاسم والتخصص والبريد والرقم في `index.html`.
2. حدّث النبذة والتعليم والمشاريع والمهارات واللغات.
3. غيّر `--brand` و`--accent` في `style.css` لتغيير الألوان.
